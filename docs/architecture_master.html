Intellectual Honesty Audit: The 5 Things You Must Build Outside the Books

The textbooks give you 85% of the machine learning and spatial math. These are the 5 external engineering layers required for a commercial launch:

1. Highway 1D Linear Referencing (LRS)

The books focus on 2D planar buffers. Billboards require snapping to a 1D highway line and subtracting exclusion intervals along the road curve.

Solution: Use Shapely line.project(point) to obtain 1D mileages, subtract 1,000-ft intervals, and reconstruct 1D candidate line segments.
2. 3D Viewshed Raycasting Algorithm

Chapter 5 gives a 2D pixel mask of tree heights, but not the 3D ray from the driver's eye (1.5m) to the billboard face (20m).

Solution: Implement parametric 3D line-of-sight raycasting testing $R(t)$ against the LiDAR elevation grid to compute clear viewing seconds at 65 mph.
3. Private Landowner & Tax Parcel CAD Data

OpenStreetMap deliberately strips out private property owner names and mailing addresses for privacy reasons.

Solution: Ingest County Central Appraisal District (CAD) open GIS datasets or integrate the Regrid / Landgrid Nationwide Parcel API.
4. Geopath Industry DEC & CPM Financial Formulas

The books teach academic regression, not Out-of-Home media buying economics.

Solution: Encode standard Geopath formulas: $\text{DEC} = \text{AADT} \times 1.4 \times \Phi_{\text{vis}}$, multiplying by digital 6-to-8 slot rotations.
5. Full-Stack SaaS Web Architecture

The notebooks output static HTML Folium files for Jupyter viewing.

Solution: Build a production FastAPI backend connected to a PostgreSQL / PostGIS database, served to a React / Next.js frontend with Mapbox GL JS vector tiles for 60fps rendering of 100,000+ parcels.
