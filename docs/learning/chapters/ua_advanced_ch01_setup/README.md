# Chapter Template Folder

**Copy this entire folder** to `docs/learning/chapters/<chapter-slug>/` when starting a new chapter.

Example:
```bash
cp -r docs/learning/template docs/learning/chapters/ua_advanced_ch01_setup
```

Then rename each file's slug in its first cell/header and start filling in.

## The 4 files

- `01_milan_original.ipynb` — you retype Milan's chapter here (create it manually as a Jupyter notebook)
- `02_milan_explanation.md` — line-by-line for Milan's chapter (I write this)
- `03_oohscout_adaptation.ipynb` — your OOHScout adaptation (create as Jupyter notebook)
- `04_adaptation_explanation.md` — line-by-line for your adaptation (I write this)

See `docs/learning/README.md` for the full workflow.
